# Week 3 — silicon curved-edge baseline

## Purpose

Week 3 converts the approximately 600 V analytical planar estimate into a
2-D silicon p-n junction. It separates three questions:

1. Does a flat numerical control reproduce the analytical target?
2. How much does a curved, unterminated edge reduce the field criterion?
3. Is the result sensitive to local mesh size?

The criterion is the reverse-bias magnitude where the maximum reconstructed
electric field crosses 262,000 V/cm. It is not an avalanche model.

## Inputs and units

The solver uses centimetres, volts, and `cm^-3`; plots use micrometres.

| Quantity | Value |
|---|---:|
| Donor concentration | `3.67e14 cm^-3` |
| Critical field criterion | `2.62e5 V/cm` |
| Analytical target | 600 V |
| Analytical depletion width | 45.9 µm |
| Relative permittivity | 11.7 |
| Temperature | 300 K |
| Electron/hole mobility | 1420 / 450 `cm²/(V s)` |
| Peak acceptors | `1e17 cm^-3` |
| Junction depth | 3 µm |
| Device width / drift thickness | 120 / 60 µm |

The acceptor profile is a smooth Gaussian diffusion. It is not the abrupt
step used by the hand calculation, so a small planar discrepancy is expected.
The finite domain, insulating outer boundaries, lifetimes, and mobilities are
modelling assumptions requiring sources before a final publication claim.

## Step 1 — inspect parameters

Read `parameters.json`. Do not change values mid-comparison. Copy the result
folder or use a new output convention before running a variant.

## Step 2 — generate and inspect the mesh

Windows:

```powershell
.\Run-Week3.cmd mesh
.\Run-Week3.cmd view-mesh
```

macOS:

```bash
./Run-Week3.sh mesh
./Run-Week3.sh view-mesh
```

The mesh is in `results/baseline_double_h1/`; inspect `mesh.png`. Gmsh
coordinates are centimetres; 0.012 cm equals 120 µm.

## Step 3 — solve equilibrium

```text
Windows: .\Run-Week3.cmd equilibrium
macOS:   ./Run-Week3.sh equilibrium
```

Inspect `equilibrium_field.png`. A built-in junction field exists at zero
applied bias.

## Step 4 — run the curved baseline

```text
Windows: .\Run-Week3.cmd run
macOS:   ./Run-Week3.sh run
```

Inspect `peak_field.csv`, `peak_field.png`, `final_field.png`, `final.vtu`,
and `summary.json`. Confirm the terminal prints `PASS`.

## Step 5 — run controls

Flat planar control:

```text
Windows: .\Run-Week3.cmd run --planar
macOS:   ./Run-Week3.sh run --planar
```

Finer local mesh:

```text
Windows: .\Run-Week3.cmd run --mesh-scale 0.7
macOS:   ./Run-Week3.sh run --mesh-scale 0.7
```

Validate all three cases:

```text
Windows: ..\ih2662.cmd week3\check_results.py
macOS:   ../ih2662.sh week3/check_results.py
```

The verified values are 127.14 V (curved baseline), 131.36 V (finer mesh),
and 591.72 V (planar control). The mesh difference is 3.21%; the planar
control is 1.38% below 600 V. This is an initial sensitivity check, not full
convergence.

## Step 6 — view the solved field

Open `Open-Week3-ParaView.cmd` on Windows or
`Open-Week3-ParaView.command` on macOS. Load `final.vtu`, select
`ElectricField_V_cm`, enable **Surface With Edges**, use **+Z**, and rescale.
The strongest field should be examined near the curved edge. `Potential_V` is
voltage, not electric-field magnitude.

## What to record

Record input snapshot, mesh size, voltage/field CSV, crossing bracket,
interpolated criterion, peak coordinates, current balance, and the exact
field-map bias. Keep planar-control and curved-edge conclusions separate.
